# 🎮 Tic Tac Toe

A simple **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**.

## Features

* Two-player game
* Winner detection
* Draw detection
* Reset Game button
* New Game button
* Responsive design

## Tech Used

* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository
2. Open `index.html` in your browser
3. Start playing 🎮
